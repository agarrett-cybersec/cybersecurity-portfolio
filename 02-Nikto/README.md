# Nikto Vulnerability Scanning
## Overview
Nikto is a web server scanner used to identify potential security issues and vulnerabilities. In this lab, I used Nikto to examine a web server and identify potential areas that could require further investigation.
## Purpose
The purpose of this lab was to understand how vulnerability scanning can help identify weaknesses in a system before they can be exploited.

## Security Takeaway
Vulnerability scanning is an important part of cybersecurity because it allows organizations to identify and address weaknesses before they can be used by an attacker.
