# John the Ripper Linux Password Cracking
## Overview
John the Ripper is a password-cracking tool commonly used to identify weak passwords on Linux systems. In this lab, I used John the Ripper in a controlled Linux environment to demonstrate how a password hash can be analyzed and cracked to recover the original password.
## Purpose
The purpose of this lab was to understand how password-cracking techniques can be used against Linux password hashes and to demonstrate the importance of using strong passwords to protect user accounts.

## Security Takeaway
Weak Linux passwords can potentially be recovered through password-cracking techniques. Using strong, unique passwords and properly securing password hashes can help reduce the risk of unauthorized access to Linux systems.
