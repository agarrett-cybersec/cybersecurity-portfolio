# My Cybersecurity Assessment Journey
## Introduction

A cybersecurity assessment is more than simply running tools and looking
for vulnerabilities. It is a process that begins with understanding the
target environment and gradually builds a picture of how systems,
networks, and applications are exposed.

This repository documents that journey.

Each directory represents a different stage of the assessment process.
As we move through each stage, we collect information, analyze what we
discover, identify potential weaknesses, and document our findings.

The goal is to go beyond learning individual tools and understand how
they work together as part of a broader security assessment. 

## The Journey

We begin with reconnaissance, where we gather information about the
target environment.

From there, we move into scanning to look for open services, weak settings, outdated software, or any issues that could lead to access being compromised.    

Next, exploitation helps us test if the weakness can be used in that environment. Sometimes attackers can use SQL injections by manipulating database queries or performing cross-site scripting in a web application.   

Further, we can explore how weaknesses are found when users prove their identity such as usernames, passwords, keys, or any other way to obtain access to a system.  
Lastly, the remaining stages provide how a security professional validates findings, analyzes potential attack paths, and ultimately documents their results.

### Assessment Stages

1. Reconnaissance
2. Vulnerability Discovery
3. Exploitation
4. Credential Security/Password Auditing
5. Threat Framework
6. Forensics/Reporting

Each directory contains notes, videos, and lessons learned
from that stage of the journey.
