# Digital Forensics with Autopsy
## Overview
Autopsy is a digital forensics platform used to examine and analyze digital evidence from sources such as disk images, files, and system data. In this lab, I used Autopsy to investigate a sample disk image and examine various types of digital evidence.
## Purpose
The purpose of this lab was to understand the role of digital forensics in investigations and learn how Autopsy can be used to identify, examine, and document evidence from a compromised or analyzed system.
## Lab Demonstration
The lab demonstrates how to open a forensic case in Autopsy, inspect data sources, and review evidence such as EXIF metadata, file extension mismatches, user accounts, recent documents, and web history. I also examined the Keyword Search ingest module and generated an HTML report documenting the findings.
## Video: [Watch Lab Demonstration](https://youtu.be/YlCPwkKu_wE)
## Security Takeaway
Digital forensics allows investigators to identify and preserve evidence that can help determine what occurred on a system. Tools such as Autopsy make it easier to analyze digital evidence, identify suspicious activity, and create detailed reports that can support security investigations.
